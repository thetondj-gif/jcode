# jcode licence disposition

## Current decision

The DAWN boundary files in this directory are independently authored and may proceed through secret-free offline testing. No jcode source, binary or packaged asset is approved for commercial redistribution by this workstream.

## Required before installation or redistribution

Record:

1. the authoritative upstream repository and exact reviewed revision;
2. the complete licence and copyright notices applying to the core project;
3. licences for bundled crates, desktop assets, skills, prompts and model/provider integrations;
4. the required notices for any binary distribution;
5. confirmation that the intended adapter path is supported rather than dependent on private internals.

## Merge gate

The offline executor authority validator may merge without installing jcode. Installation, model use, repository access and redistribution remain separate decisions.
