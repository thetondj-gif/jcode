# Acceptance ladder

```text
BOUNDARY_IMPLEMENTED
→ REMOTE_OFFLINE_CHECKS_PASS
→ MAC_OFFLINE_VALIDATOR_PASS
→ EXECUTOR_ADAPTER_IMPLEMENTED
→ PROCESS_AND_ENVIRONMENT_SANDBOX_PROVEN
→ READ_ONLY_FIXTURE_CANARY
→ OUTPUT_AND_RESOURCE_REVIEW
→ SEPARATE_WRITE_CAPABILITY_DECISION
```

Repository merge proves only that the authority boundary exists. It does not prove jcode is installed, invoked, connected to a provider, permitted to inspect a real repository or connected to DAWN.
